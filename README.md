# FastAPI Mastery

This repository hosts a curated list of FastAPI practice projects, progressing from beginner to advanced levels. It is designed for learning purposes and built using best practices. Each project represents a step up in complexity, allowing anyone to start learning and climb the ladder systematically.

This is a continuously updated repository.

## Features

- Progressive difficulty levels across projects.
- Focus on modern FastAPI best practices.
- Ruff is used for linting and formatting.
- Automation is handled via Justfile and custom scripts.

## Getting Started

1. Clone the repository.
2. Follow the instructions within each project directory.
3. Use the Justfile commands (e.g., `just cq`) to run local checks.
