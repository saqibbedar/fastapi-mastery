# Contributing Guidelines

We welcome contributions to FastAPI Mastery. This repository is for learning and mastering FastAPI.

## Workflow

1. Fork the repository.
2. Clone your fork locally.
3. Create a new branch for your work.
4. Make your changes or fix bugs.
5. Run code quality checks using the provided Justfile (`just code_quality`).
6. Verify the generated logs and fix any errors before committing.
7. Push your branch to your fork.
8. Submit a Pull Request using the provided PR template.

## Rules

- Direct pushes to the main branch are rejected.
- All code must pass the automated GitHub Actions linting workflow. If the workflow fails, the PR will not be merged.
- Keep your code clean and follow best practices.
- Use descriptive names for your files and variables.
