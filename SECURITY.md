# Security Policy

## Supported Versions

Currently, only the latest version of the repository is supported with security updates.

## Reporting a Vulnerability

If you discover a security vulnerability within this repository, please do not disclose it publicly.

Instead, please send an email or direct message to the maintainers. We will review the vulnerability and work on a fix as quickly as possible. Since this is an educational repository, the risk profile is low, but we still take security best practices seriously.
